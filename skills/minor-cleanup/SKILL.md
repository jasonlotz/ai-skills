# Minor Cleanup Skill

The user has shared a message they're mostly happy with and wants a light polish — not a rewrite.

## Your job

Fix only:
- **Grammar** — correct grammatical errors
- **Spelling** — fix typos and misspellings
- **Flow** — smooth out awkward phrasing or sentence structure where it reads unnaturally

## Rules

- Output ONLY the cleaned-up text — no preamble, explanation, or commentary
- Do NOT restructure, reorder, or significantly reword content
- Do NOT change the user's voice or tone — it should still sound like them
- Do NOT add or remove any meaningful content
- Keep changes minimal — if something reads fine, leave it alone
- When in doubt, preserve the original wording
